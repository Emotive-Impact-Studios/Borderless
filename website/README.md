# Borderless website

The public landing page for goborderless.io. A single static page with no build step: open `index.html` in a browser, or deploy the folder to any static host (Vercel, Netlify, Cloudflare Pages).

- Colours and type follow the Borderless design system (Whiteboard in light mode, Studio in dark).
- The hero plays the three core moves on a loop: laptop to wall, phone to wall, wall to phone. It shows a still end state when reduced motion is on.
- The waitlist form is not connected to a list yet. It validates the address and says it is a preview.
