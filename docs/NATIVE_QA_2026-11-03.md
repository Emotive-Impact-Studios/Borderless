The Swift source uses a bounded latest-frame mailbox and rejects incomplete/invalid pixel buffers. The test establishes no complete frames reached that boundary; it does not distinguish an OS delivery failure from every possible filter/attachment/adapter defect. Instrument raw callback/status counts next, then inspect OS capture logs and source lifecycle. Do not assume permission denial or a network fault. This adapter currently has no network media code.

The first picker lifecycle implementation deactivated the picker before starting its new filter; that was corrected to keep the picker active across replacement. The repeated failed test is the current result. Stop sharing then showed “Sharing stopped”, disabled its action and cleared the local preview; the diagnostic app was quit. No saved user room, unrelated application or desktop content was used as a source.

Godot's first editor import could not locate the SDK when only DOTNET_ROOT was set. Adding the SDK directory to PATH resolved it; editor import and the scene gate subsequently passed. The verification script checks engine ERROR diagnostics as well as exit status because Godot can exit zero after an error.

## Not verified or not implemented

Native encode/decode/network media, useful native file/PDF/video viewers, native personal receiving windows, complete spatial interaction, Go server parity/data migration, Windows capture/IDD/signing, macOS virtual display, physical iPhone/Android/second-computer sessions, room audio, multihead/scanout, WebAuthn, SQLCipher, HA and production releases remain open. A .NET test on Mac is not a Windows test. A headless scene is not user visual acceptance.

Native CI is added separately from the existing web/Electron jobs. Remote job outcomes must be checked at the pushed commit; this local report does not assert hosted success.
