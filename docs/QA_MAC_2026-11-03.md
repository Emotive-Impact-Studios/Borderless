## Defects fixed during acceptance

- A macOS capture source dialog suspended Electron's main event loop and stalled the in-process room server. The hub now runs in its own utility process; HTTP remained responsive while the real picker was open. Automated acceptance also reproduces a blocked native thread.
- Active sharing had an icon-only toggle still labelled Share your screen. It now exposes a visible Stop sharing button and the correct accessible state. A pending source selection disables duplicate requests.
- Expired socket sessions could receive a room broadcast until the heartbeat retired them. Broadcast/outbound checks now close expired access immediately.
- Session credentials and command receipts accumulated indefinitely. Inactive session data now retires at startup and on the 30-second maintenance cycle, without deleting current-session retry receipts or saved contributions.
